```
scripts/
├── requirements.txt   # pip dependencies
├── models.yaml        # which models to benchmark (edit to add/remove)
```

The Stage 1-5 and Stage 6/7 benchmark/scoring scripts that used to live
here (`run_benchmark.py`, `score.py`, `bug_classes.py`,
`run_benchmark_firmware.py`, `score_firmware.py`) were removed on
2026-07-17 (branch `W2/skills-creation`) — per the supervisor's guidance,
their methodology (Tier A) is still correct, but the scripts themselves
are being regenerated by Codex as part of Stage 8's skill-based
automation, for both the function-level (Tier A) and codebase-level
(Tier B) tasks. See `PLAN.md`/`PIPELINE.md` (Stage 8) and `LOG.md`
(2026-07-16/17 entries) for the full reasoning. Still findable in git
history / on `W1/firmware-static-analysis` if needed for reference.

`ExportAllFunctions.java` is kept — it's extraction tooling (bulk
Ghidra decompilation), not benchmark/scoring logic, and is still the
expected way to get a codebase into pseudo-C for Stage 8's automation to
consume.

## Setup

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r scripts/requirements.txt
```

## API keys

Get keys from each provider's dashboard, then export them as environment
variables (the SDKs read these automatically — nothing to configure in
code):

```bash
export ANTHROPIC_API_KEY="sk-ant-..."
export OPENAI_API_KEY="sk-..."
```

- Anthropic: https://console.anthropic.com/ → Settings → API Keys.
- OpenAI: https://platform.openai.com/api-keys.

## `models.yaml`

One entry per model to benchmark:

```yaml
models:
  - provider: anthropic
    model: claude-fable-5
  - provider: openai
    model: gpt-5.6-sol
```
